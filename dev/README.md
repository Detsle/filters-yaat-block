# DEV-фильтры Я@ Block

Это отдельный набор экспериментальных CSS-правил для локальной DEV-сборки расширения.

## Файлы

- `dev-manifest.json` — номер DEV revision, время публикации и SHA-256/размеры файлов.
- `dzen.css` — тестовые правила категории Дзен.
- Для других категорий создавайте файлы с соответствующими именами: `dzen-suggest.css`, `mailru.css`, `yandex-search.css` и т. д., затем добавляйте их в `categories` манифеста с ключом категории движка.

## Обновление DEV

При каждом изменении любого CSS-файла увеличивайте `revision` на 1 и пересчитывайте `sha256` и `bytes` изменённых файлов. Релизный `filterVersion` в корневом `filters-manifest.json` не меняется.

DEV применяются только локальной сборкой и только при включённом переключателе в popup. Магазинная сборка не загружает эту папку.

После принятия правила переносится в соответствующий файл `filters/*.css`, удаляется из DEV-файла, затем увеличивается patch-версия релизной базы и обновляется её манифест.
